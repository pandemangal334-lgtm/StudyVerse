FCFS numerical lab

Enter processes in the order shown. The lab sorts by arrival time; for equal arrival times, original row order is used. Gantt chart starts at time 0 and shows CPU idle time when needed.

Formulas
CT = completion time
TAT = CT − AT
WT = TAT − BT
RT = first start time − AT
Average = sum of values ÷ number of processes

Mock test • 20 marks

5 MCQs (1 mark each) + 1 short answer (5 marks) + 1 numerical task (10 marks). The short answer is self-check; MCQs are auto-graded.

Short answer (5 marks)

Explain PCB and write any four fields stored in it.

Numerical task (10 marks)

For P1 (AT=0, BT=4), P2 (AT=1, BT=3), P3 (AT=2, BT=1), make FCFS order and calculate CT, TAT and WT.
