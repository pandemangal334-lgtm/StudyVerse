2.1 · Source topic

Recursion kya hai?

Recursion ek technique hai jisme function apne aap ko call karta hai, usually smaller input ke saath, jab tak base/stopping condition meet na ho.

Simple example: countdown(3) → countdown(2) → countdown(1) → stop. Base case nahi hua toh calls rukengi nahi aur stack overflow ho sakta hai.

Do essential parts: base case (kab rukna hai) + recursive case (problem ko chhota karke dobara solve karna).

2.3 · Factorial

Factorial of n

Mathematically: n! = n × (n−1) × … × 1, and 0! = 1.

fact(n):
  if n <= 1: return 1
  return n * fact(n-1)

Example: fact(4) = 4 × fact(3) = 4 × 3 × 2 × 1 = 24.

2.4 · Towers of Hanoi

3 towers, n disks

Goal: saare disks source tower se destination tower par move karo. Ek time par ek disk move; bigger disk smaller disk ke upar nahi rakh sakte.

Recurrence: T(n) = 2T(n−1) + 1, T(1)=1. Minimum moves = 2ⁿ − 1. For 3 disks: 7 moves; for 4: 15 moves.
2.5 · Fibonacci

Fibonacci sequence

Source definition starts with 0 and 1; every next value is previous two ka sum.

fib(n):
  if n == 0 or n == 1: return n
  return fib(n-1) + fib(n-2)

Sequence: 0, 1, 1, 2, 3, 5, 8, 13, 21…

Note: the naive recursive version repeats calculations (e.g. fib(2) appears multiple times), as discussed in the PDF.

2 marks

Define recursion.

Recursion is a programming technique in which a function calls itself to solve a smaller instance of the same problem. A base case stops further calls.

2 marks

What is a base case?

A base case is the stopping condition in a recursive function. It returns a result without making another recursive call and prevents endless recursion.

4 marks

Differentiate recursion and iteration.

1. Recursion uses repeated function calls; iteration uses loops. 2. Recursion uses the call stack for each active call; iteration generally reuses loop state. 3. Recursion ends at a base case; iteration ends when its loop condition becomes false. 4. Recursion can be clearer for naturally recursive problems, while iteration may avoid function-call overhead.

4 marks

Explain Fibonacci using recursion.

F(0)=0 and F(1)=1 are base cases. For n≥2, F(n)=F(n−1)+F(n−2). The function calls itself for the two previous positions and adds their values. Example: F(5)=F(4)+F(3)=3+2=5. Naive recursion repeats subproblems.

6 marks

Explain Towers of Hanoi with algorithm and recurrence.

For n disks, move the top n−1 disks from source to auxiliary, move the largest disk from source to destination, then move n−1 disks from auxiliary to destination. Base case: for one disk, move it directly. Recurrence: T(n)=2T(n−1)+1 with T(1)=1. Therefore T(n)=2ⁿ−1. For n=3, the minimum is 7 moves.

TOH(n, source, auxiliary, destination):
  if n == 1:
    print move source → destination
    return
  TOH(n-1, source, destination, auxiliary)
  print move source → destination
  TOH(n-1, auxiliary, source, destination)
6 marks

Explain recursive factorial with trace.

Factorial is n! = n × (n−1)! for n>1, with 0!=1 and 1!=1. The recursive case reduces n by one. Example: fact(4) → 4×fact(3) → 4×3×fact(2) → 4×3×2×fact(1) → 24. Each call returns after the base case is reached.

1. Factorial (C)

#include <stdio.h>
long long fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
int main(void) {
    int n = 5;
    printf("%d! = %lld\\n", n, fact(n));
    return 0;
}

Output:

5! = 120

Clean, standard-C supplementary version; source PDF's chapter includes a factorial example but its formatting reflects older compiler conventions.

2. Fibonacci (C)

#include <stdio.h>
int fib(int n) {
    if (n == 0 || n == 1) return n;
    return fib(n - 1) + fib(n - 2);
}
int main(void) {
    for (int i = 0; i < 8; i++) printf("%d ", fib(i));
    printf("\\n");
    return 0;
}

Output:

0 1 1 2 3 5 8 13

3. Towers of Hanoi (C)

#include <stdio.h>
void hanoi(int n, char from, char aux, char to) {
    if (n == 1) {
        printf("Move disk 1 from %c to %c\\n", from, to);
        return;
    }
    hanoi(n-1, from, to, aux);
    printf("Move disk %d from %c to %c\\n", n, from, to);
    hanoi(n-1, aux, from, to);
}
int main(void) {
    hanoi(3, 'A', 'B', 'C');
    return 0;
}

Output (7 moves):

Move disk 1 from A to C
Move disk 2 from A to B
Move disk 1 from C to B
Move disk 3 from A to C
Move disk 1 from B to A
Move disk 2 from B to C
Move disk 1 from A to C

4. GCD of two integers (Euclid's algorithm)

#include <stdio.h>
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
int main(void) {
    printf("GCD = %d\\n", gcd(99, 55));
    return 0;
}

Output:

GCD = 11

Last-minute revision sheet

  • Recursion = function calling itself.
  • Always identify the base case and recursive case.
  • Factorial: n! = n × (n−1)!, with 0! = 1.
  • Fibonacci: F(0)=0, F(1)=1, F(n)=F(n−1)+F(n−2).
  • Towers of Hanoi: T(n)=2T(n−1)+1; minimum moves 2ⁿ−1.
  • Naive Fibonacci recursion recomputes overlapping subproblems.
  • Recursion uses the runtime call stack; excessive depth can cause stack overflow.
  • PDF topics also include recursive NCR, LCM and GCD programs.
