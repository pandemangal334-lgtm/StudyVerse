4.1 · Stack

Stack kya hai?

A stack is a list in which insertion and deletion happen only at one end called TOP. It follows LIFO — Last In, First Out.

Hinglish: plates ka stack socho. Last mein rakhi plate pehle nikalti hai. Push = add, Pop = remove.

Array stack commonly uses an integer top; when empty, a common convention is top = -1. Fixed capacity can cause overflow; popping an empty stack causes underflow.

Conversion example

Infix to postfix

Expression: (A + B) * (C - D) / E

  1. (A+B) → AB+
  2. (C-D) → CD-
  3. Multiply the two results → AB+CD-*
  4. Divide by E → AB+CD-*E/

Rule: operands go directly to output; operators are managed by a stack according to precedence and parentheses.

Worked explanation of an expression appearing in the source chapter's MCQs.

Postfix evaluation

Operand stack method

Read left to right. If token is an operand, push it. If token is an operator, pop right operand first, then left operand; calculate left operator right, and push result.

Example: 5 3 + 2 * → push 5, push 3, add → 8, push 2, multiply → 16.

Order matters for subtraction and division. For 8 2 /, pop 2 first as right operand, then 8 as left operand: result 4.

4.6 · Queue

Queue kya hai?

A queue inserts at REAR and deletes at FRONT. It follows FIFO — First In, First Out.

Hinglish: canteen ki line. Jo pehle line mein aaya, uska turn pehle.

Enqueue inserts at rear; dequeue deletes from front. A simple linear array queue can leave unused spaces at the beginning after deletions.

4.8–4.10 · Queue variants

Circular queue, deque, priority queue

  • Circular queue: last array position wraps to first using modulo; can reuse freed positions.
  • Deque: additions and deletions can be performed at either end.
  • Priority queue: higher-priority items are processed first; equal-priority items follow arrival order, as described in the PDF.

Queues model waiting lines and first-come-first-served processing. The source chapter focuses on array/linked-list representations and circular, deque and priority queue variants.

Define overflow and underflow.

Overflow: trying to push into a full fixed-capacity stack. Underflow: trying to pop from an empty stack.

4 marks

Differentiate stack and queue.

1. Stack follows LIFO; queue follows FIFO. 2. Stack insertion/deletion occurs at TOP; queue insertion occurs at REAR and deletion at FRONT. 3. Stack operations are push/pop; queue operations are enqueue/dequeue. 4. Stacks are used in expression conversion/evaluation and function calls; queues represent first-come-first-served processing.

4 marks

Explain infix, postfix and prefix notation.

In infix, operator is between operands: A+B. In postfix, operator follows operands: AB+. In prefix, operator precedes operands: +AB. Postfix and prefix can be evaluated using stacks without relying on the usual infix precedence rules during evaluation.

6 marks

Explain stack representation and operations.

A stack is a linear list that follows LIFO. In array representation, a fixed-size array stores elements and a TOP variable identifies the current top element. Initially TOP is commonly set to -1. PUSH checks whether the stack is full; if full, overflow occurs. Otherwise increment TOP and store the new item. POP checks whether TOP is -1; if empty, underflow occurs. Otherwise return the top item and decrement TOP.

PUSH(S, x):
  if TOP == MAX-1: report overflow
  else:
    TOP = TOP + 1
    S[TOP] = x

POP(S):
  if TOP == -1: report underflow
  else:
    x = S[TOP]
    TOP = TOP - 1
    return x

Exam-ready algorithm explanation. TOP=-1 is a common implementation convention; the source diagram may use its own indexing convention.

6 marks

Explain queue and circular queue.

A queue follows FIFO. Enqueue inserts at REAR and dequeue removes from FRONT. In a simple linear array queue, REAR may reach the last array index even when earlier positions have become empty after deletions; this can waste space unless elements are shifted. A circular queue logically connects the last position back to the first and uses wrap-around indexing to reuse free positions.

next = (index + 1) % MAX
6 marks

Explain infix-to-postfix conversion.

Scan the infix expression from left to right. Send operands directly to output. Push a left parenthesis. On a right parenthesis, pop operators to output until the matching left parenthesis is removed. For an operator, pop operators of higher precedence (and equal precedence when the operator is left-associative), then push the current operator. After scanning all input, pop remaining operators to output. Handle associativity carefully, especially exponentiation.

1. Stack using array — push, pop, display

#include <stdio.h>
#define MAX 5
int s[MAX], top = -1;

void push(int x) {
    if (top == MAX - 1) {
        puts("Stack overflow");
        return;
    }
    s[++top] = x;
}
void pop(void) {
    if (top == -1) {
        puts("Stack underflow");
        return;
    }
    printf("Popped: %d\\n", s[top--]);
}
void display(void) {
    if (top == -1) { puts("Stack empty"); return; }
    for (int i = top; i >= 0; --i) printf("%d\\n", s[i]);
}
int main(void) {
    push(10); push(20); push(30);
    puts("Stack top to bottom:");
    display();
    pop();
    puts("After pop:");
    display();
    return 0;
}
Output
Stack top to bottom:
30
20
10
Popped: 30
After pop:
20
10

2. Queue using array — enqueue and dequeue

#include <stdio.h>
#define MAX 5
int q[MAX], front = 0, rear = -1;

void enqueue(int x) {
    if (rear == MAX - 1) { puts("Queue full"); return; }
    q[++rear] = x;
}
void dequeue(void) {
    if (front > rear) { puts("Queue empty"); return; }
    printf("Removed: %d\\n", q[front++]);
}
void display(void) {
    if (front > rear) { puts("Queue empty"); return; }
    for (int i = front; i <= rear; ++i) printf("%d ", q[i]);
    puts("");
}
int main(void) {
    enqueue(11); enqueue(22); enqueue(33);
    display();
    dequeue();
    display();
    return 0;
}
Output
11 22 33
Removed: 11
22 33

This simple linear queue does not reuse the freed front slots. Circular queue is designed to address that limitation.
