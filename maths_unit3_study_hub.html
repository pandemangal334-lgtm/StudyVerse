1. Random variable, PMF aur PDF

Simple samjho: Random experiment ke result ko number dene wala variable random variable kehlata hai. Jaise 2 coins toss kiye aur X = heads ki count, toh X ki values 0, 1, 2 ho sakti hain.

Discrete: Countable values (0, 1, 2...). Continuous: Range mein koi bhi value ho sakti hai.

PMF: Discrete variable ki har value ki probability. PDF: Continuous variable ke liye density function; probability interval ke area/integral se milti hai.

2. Expectation — average ka probability version

Har value ko uski probability se multiply karo, phir sab add karo.

E(X) = Σ x·p(x)

PDF example: 2 coins X = number of heads; P(X=0)=1/4, P(X=1)=1/2, P(X=2)=1/4.

E(X) = 0(1/4) + 1(1/2) + 2(1/4) = 1

Matlab long-run average heads per two-coin experiment = 1.

Continuous case mein PDF ke according expectation integral se calculate hoti hai.

3. Variance aur standard deviation

Expectation average batata hai; variance batata hai values average se kitni spread hain.

Var(X) = E(X²) − [E(X)]²
SD(X) = √Var(X)

PDF example: X values 0, 1, 2, 3 aur probabilities 1/3, 1/2, 0, 1/6. Notes ke result: E(X)=1, E(X²)=2.

Var(X)=2−1²=1; SD=√1=1

4. Moments aur MGF

r-th raw moment: origin ke about moment.

μ′ᵣ = E(Xʳ)

Moment generating function (MGF):

Mₓ(t) = E(eᵗˣ)

PDF example: X = +1 or −1, each with probability 1/2.

Mₓ(t) = (eᵗ + e⁻ᵗ)/2 = cosh(t)

Is example mein raw moments: μ′₁=0, μ′₂=1, μ′₃=0, μ′₄=1.

PDF exponential example: f(x)=e⁻ˣ for x≥0; MGF = 1/(1−t), and first four raw moments = 1, 2, 6, 24 (where the MGF exists).

5. Joint expectation, covariance, correlation

Jab X aur Y dono variables saath diye ho, joint distribution table use hota hai.

E(XY) = ΣΣ xy·p(x,y)

Har (x,y) pair ke liye x×y karo, us joint probability se multiply karo, phir sab add karo.

Cov(X,Y) = E(XY) − E(X)E(Y)

Covariance X aur Y saath kaise change karte hain, ye measure karta hai.

Corr(X,Y) = Cov(X,Y) / (σₓσᵧ)

Correlation covariance ko dono standard deviations se scale karta hai.

Important 2-mark questions with answers

1. Define random variable.
A random variable is a function that assigns a numerical value to each outcome of a random experiment.
2. What is PMF?
Probability Mass Function gives the probability of each possible value of a discrete random variable.
3. Define mathematical expectation.
For a discrete random variable, E(X)=Σxp(x), where x is a possible value and p(x) is its probability.
4. Define variance.
Variance measures spread around the mean and is calculated as Var(X)=E(X²)−[E(X)]².
5. What is an r-th raw moment?
The r-th raw moment about origin is μ′ᵣ=E(Xʳ).
6. Define MGF.
The moment generating function is Mₓ(t)=E(eᵗˣ).
7. Define covariance.
Covariance measures how two random variables vary together: Cov(X,Y)=E(XY)−E(X)E(Y).
8. Define correlation coefficient.
Correlation is standardized covariance: Corr(X,Y)=Cov(X,Y)/(σₓσᵧ).

Important 4-mark answers

1. Find expectation for the two-coin example.

Let X be the number of heads when two coins are tossed.

P(X=0)=1/4, P(X=1)=1/2, P(X=2)=1/4.

E(X)=Σxp(x)

E(X)=0(1/4)+1(1/2)+2(1/4)=0+1/2+1/2=1.

Therefore, E(X)=1.
2. Find variance and SD for the PDF's discrete example.

Given X=(0,1,2,3), P(X)=(1/3,1/2,0,1/6). From the PDF example, E(X)=1 and E(X²)=2.

Var(X)=E(X²)−[E(X)]²=2−1=1
SD(X)=√Var(X)=√1=1
Variance = 1 and standard deviation = 1.
3. Find MGF for X=+1 and −1, each with probability 1/2.

By definition, Mₓ(t)=E(eᵗˣ).

Mₓ(t)=eᵗ(1/2)+e⁻ᵗ(1/2)=(eᵗ+e⁻ᵗ)/2=cosh(t)
Hence MGF = cosh(t).
4. Explain joint expectation and covariance.

For a discrete joint distribution, multiply x and y for each pair and weight it by its joint probability:

E(XY)=ΣΣxy·p(x,y)

Then calculate individual expectations E(X), E(Y). Use:

Cov(X,Y)=E(XY)−E(X)E(Y)

Show the joint table calculations clearly and substitute the final values.

5. Explain correlation coefficient.

Correlation expresses the standardized relationship between two random variables. First calculate covariance, then divide it by the product of the standard deviations.

Corr(X,Y)=Cov(X,Y)/(σₓσᵧ)

In an exam answer, define the symbols and show the substitution step.
