High-value differences to remember

this vs super

this refers to the current object/current class context; super accesses the immediate parent class's members or constructor.

this() vs super()

this() calls another constructor in the same class; super() calls a superclass constructor. Both must be the first statement when used in a constructor.

Inheritance reminder

Java classes cannot directly extend two classes. Multiple inheritance of type can be achieved by implementing multiple interfaces.

Inheritance in Java

Inheritance is a mechanism in which one object/class acquires properties and behaviours of a parent class. It supports code reuse and organization. It represents an IS-A relationship.

Key terminology

  • Superclass / parent / base class: class whose features are inherited.
  • Subclass / child / derived class: class that inherits from another class.
  • Reusability: reusing existing fields and methods instead of rewriting them.

extends syntax

class SubclassName extends SuperclassName {
    // fields and methods
}

Example: Employee → Programmer

class Employee {
    float salary = 40000;
}
class Programmer extends Employee {
    int bonus = 10000;
}
public class Main {
    public static void main(String[] args) {
        Programmer p = new Programmer();
        System.out.println("Programmer salary is:" + p.salary);
        System.out.println("Bonus of Programmer is:" + p.bonus);
    }
}

Output

Programmer salary is:40000.0
Bonus of Programmer is:10000
A Programmer is an Employee; the child object can access the inherited salary field and its own bonus field.

Types of inheritance

1. Single inheritance

One child inherits from one parent.

class Animal {
    void eat() { System.out.println("eating..."); }
}
class Dog extends Animal {
    void bark() { System.out.println("barking..."); }
}
public class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.bark();
        d.eat();
    }
}
barking...
eating...

2. Multilevel inheritance

Inheritance forms a chain: Animal → Dog → BabyDog.

class Animal {
    void eat() { System.out.println("eating..."); }
}
class Dog extends Animal {
    void bark() { System.out.println("barking..."); }
}
class BabyDog extends Dog {
    void weep() { System.out.println("weeping..."); }
}
public class Main {
    public static void main(String[] args) {
        BabyDog d = new BabyDog();
        d.weep(); d.bark(); d.eat();
    }
}

3. Hierarchical inheritance

Two or more child classes inherit from the same parent, e.g. Dog and Cat extend Animal.

class Animal { void eat(){ System.out.println("eating..."); } }
class Dog extends Animal { void bark(){ System.out.println("barking..."); } }
class Cat extends Animal { void meow(){ System.out.println("meowing..."); } }
public class Main {
    public static void main(String[] args) {
        Cat c = new Cat();
        c.meow(); c.eat();
    }
}

4. Multiple inheritance

A class inheriting from multiple parent classes. The notes explain Java does not support this directly through classes because conflicting inherited methods can cause ambiguity (diamond problem). Java supports implementing multiple interfaces.

// Conceptual illustration of the conflict — invalid Java syntax:
class Main extends A, B { }

5. Hybrid inheritance

A combination of two or more inheritance types. The notes list combinations such as multilevel + hierarchical. In Java, combinations requiring multiple class inheritance use interfaces instead.

// Simplified pattern shown in the notes:
class C { public void disp(){ System.out.println("C"); } }
class A extends C { public void disp(){ System.out.println("A"); } }
class B extends C { public void disp(){ System.out.println("B"); } }
class D extends A {
    public void disp(){ System.out.println("D"); }
    public static void main(String[] args) {
        D obj = new D();
        obj.disp();
    }
}
// Output: D
PDF diagram reminder: the inheritance diagrams on pages 5–7 show a chain for multilevel, sibling subclasses for hierarchical, and a combined family-style structure for hybrid inheritance.

Why is multiple inheritance not supported through classes?

The notes use the diamond problem: if two parent classes provide a same-named method, a child may face ambiguity about which implementation to use. Java rejects extending two classes at compile time.

How to achieve it? Implement multiple interfaces.

Exam phrasing: “Java does not support multiple inheritance using classes to avoid ambiguity and complexity; it supports multiple inheritance through interfaces.”

Constructors in inheritance

When an object of a child class is created, the parent constructor runs before the child constructor. If no explicit parent constructor call is written, Java inserts a no-argument super() call when possible.

class Parent {
    Parent() { System.out.println("Parent class constructor called"); }
}
class Child extends Parent {
    Child() { System.out.println("Child class constructor called"); }
}
public class Main {
    public static void main(String[] args) { Child obj = new Child(); }
}

Parameterized constructor example

class Parent {
    int a;
    Parent() { a = 10; }
}
class Child extends Parent {
    int b;
    Child(int x) { b = x; }
    void display() {
        System.out.println("a = " + a);
        System.out.println("b = " + b);
    }
}
public class Main {
    public static void main(String[] args) {
        Child obj = new Child(20);
        obj.display();
    }
}

b = 20

Constructor chaining

Constructor chaining calls one constructor from another. The notes cover chaining within the same class using this(), and parent-class chaining using super().

Same class using this()

class Temp {
    Temp() {
        this(5);
        System.out.println("The Default constructor");
    }
    Temp(int x) {
        this(5, 15);
        System.out.println(x);
    }
    Temp(int x, int y) {
        System.out.println(x * y);
    }
    public static void main(String[] args) { new Temp(); }
}

Rules to remember

  • this() must be the first statement in its constructor.
  • super() must be the first statement in a child constructor.
  • Use this() for another constructor in the same class.
  • Use super() to call a parent constructor.
  • Constructor chaining helps reduce duplicated initialization code.

Chaining with super(name)

class Base {
    Base(String name) {
        System.out.println("Calling parameterized constructor of base");
    }
}
class Derived extends Base {
    Derived(String name) {
        super(name);
        System.out.println("Calling parameterized constructor of derived");
    }
}

Initialization block

An instance initialization block runs before the constructor whenever an object is created. If multiple blocks exist, they run in source order.

class Temp {
    { System.out.println("init block"); }
    Temp() { System.out.println("default"); }
    Temp(int x) { System.out.println(x); }
    public static void main(String[] args) {
        new Temp();
        new Temp(10);
    }
}

The super keyword

super is used to refer to the immediate parent class context.

1. Access parent variable

class Parent { String name = "Parent Class"; }
class Child extends Parent {
    String name = "Child Class";
    void display() {
        System.out.println(name);
        System.out.println(super.name);
    }
}
Child Class
Parent Class

2. Access parent method

class Parent {
    void message() { System.out.println("Hello from Parent"); }
}
class Child extends Parent {
    @Override
    void message() { System.out.println("Hello from Child"); }
    void test() {
        message();
        super.message();
    }
}

Expected output from test()

Hello from Child
Hello from Parent

3. Call parent constructor

Use super(arguments) to call the parent constructor. It must be the first statement in the child constructor. If the parent has only a parameterized constructor, the child must pass suitable arguments.

The this keyword

this refers to the current object. The notes highlight these uses:

1. Distinguish instance variable and parameter

class Student {
    private String name;
    public Student(String name) {
        this.name = name;
    }
}

this.name is the instance field; name is the constructor parameter.

2. Invoke current-class method

class Calculator {
    public void printTotal() {
        System.out.println("Processing calculation...");
    }
    public void compute() {
        this.printTotal();
    }
}

3. Chain constructors with this()

class Account {
    private String accountType;
    private double balance;
    public Account() {
        this("Savings", 0.0);
    }
    public Account(String accountType, double balance) {
        this.accountType = accountType;
        this.balance = balance;
    }
}
The PDF lists constructor chaining benefits as reduced duplication and improved readability; it also notes that exposing many constructor paths can sometimes be a drawback in larger designs.

2-mark answers

Define inheritance.

Inheritance is an OOP mechanism in which a class acquires fields and methods from another class. It supports code reusability and represents an IS-A relationship.

What are superclass and subclass?

A superclass is the parent/base class whose features are inherited. A subclass is the child/derived class that inherits features from the superclass.

What is constructor chaining?

Constructor chaining is calling one constructor from another. this() calls a constructor in the same class and super() calls a parent-class constructor.

State two uses of super.

It accesses parent-class variables or methods and invokes a parent-class constructor.

4-mark answers

Explain any four types of inheritance.

Single: one subclass inherits one superclass. Multilevel: inheritance forms a chain. Hierarchical: multiple subclasses inherit one superclass. Hybrid: combination of inheritance types; combinations requiring multiple class inheritance can use interfaces in Java.

Why does Java not support multiple inheritance through classes?

It can create ambiguity when two parent classes contain the same method or field (diamond problem). Java rejects extending multiple classes at compile time. Multiple interfaces can be implemented instead.

Differentiate this and super.

this refers to the current object and is used for current fields, methods and same-class constructor chaining. super accesses the immediate parent class's fields/methods and calls its constructor.
