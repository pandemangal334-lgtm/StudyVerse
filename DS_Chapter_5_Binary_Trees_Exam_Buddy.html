5.1 Trees — basic idea

Tree: nodes ka hierarchical collection. Top node root hota hai. Root ka parent nahi hota. Parent se neeche linked nodes children kehlate hain. Jis node ke children nahi hote, woh leaf node hai. Har child apne subtree ka root bhi hota hai.

A ← root / \\ B C / \\ \\ D E F ← leaves: D, E, F

Hinglish: family tree jaisa structure — root se branches nikalti hain. General graph mein cycles ho sakte hain; tree mein cycle nahi hota aur nodes hierarchical relation mein hote hain.

5.2 Binary Tree

Definition: Binary tree either empty hota hai, ya ek root node aur uske left subtree aur right subtree se milkar banta hai. Har node ke maximum two children: left and right.

A / \\ B C / \\ / \\ D E F G

Terminology: root (A), parent (B is parent of D/E), children (D and E), siblings (B and C), leaf/external node (D/E/F/G), internal node (A/B/C), path (A→B→D), subtree (B with D and E).

TypeMeaning
Full / strict binary treeHar node ke 0 ya exactly 2 children.
Complete binary treeLast level ke alawa levels filled; last level left se fill hota hai.
Perfect binary treeAll internal nodes ke 2 children aur all leaves same level par.
Skewed treeHar internal node ka ek hi child; left- ya right-skewed.
Terminology note: textbooks kabhi “full” aur “complete” ko alag naming conventions se use karte hain. Exam mein apne PDF ki definition aur diagram follow karna.

5.3 Traversal techniques

Traversal means har node ko ek defined order mein visit karna.

A / \\ B C / \\ / \\ D E F G
TraversalRuleOutput for above tree
PreorderRoot → Left → Right (NLR)A B D E C F G
InorderLeft → Root → Right (LNR)D B E A F C G
PostorderLeft → Right → Root (LRN)D E B F G C A
Level orderLevel by level, usually queueA B C D E F G

Recursive algorithms (exam format)

PREORDER(node)
  if node != NULL:
    visit(node)
    PREORDER(node.left)
    PREORDER(node.right)

INORDER(node)
  if node != NULL:
    INORDER(node.left)
    visit(node)
    INORDER(node.right)

POSTORDER(node)
  if node != NULL:
    POSTORDER(node.left)
    POSTORDER(node.right)
    visit(node)

Memory trick: Pre = root pehle; In = root beech mein; Post = root last.

Building a tree from traversal pairs

Common method: unique node values hone par Preorder + Inorder ya Postorder + Inorder se tree reconstruct kar sakte hain.

Example: Preorder = A B D E C F, Inorder = D B E A F C.

  1. Preorder ka first element A root hai.
  2. Inorder mein A ke left mein D B E, right mein F C: left/right subtrees identify karo.
  3. Har subtree par same rule recursively apply karo.
Duplicate keys ke case mein traversal pairs se unique tree zaroori nahi milta. Ye uniqueness assumption supplementary explanation hai.

5.5 Threaded binary tree

Ordinary binary tree mein missing left/right child pointers NULL hote hain. Threaded binary tree mein aise NULL pointers ko traversal order ke predecessor/successor node ki taraf thread ke roop mein use kiya ja sakta hai, taaki traversal mein stack/recursion ki need kam ho.

Thread type identify karte waqt check karo: left thread predecessor ko point kar sakta hai; right thread successor ko. Thread-vs-child ko distinguish karne ke liye tag/flag use ho sakta hai.

5.6 Binary Search Tree (BST)

BST property: har node ke left subtree ke keys node se smaller, aur right subtree ke keys larger hote hain (duplicate handling implementation par depend karta hai).

50 / \\ 30 70 / \\ / \\ 20 40 60 80
  • Search: key compare karo; smaller ho to left, larger ho to right.
  • Insert: same comparisons follow karke NULL position par node add karo.
  • Delete: leaf → remove; one child → child se replace; two children → inorder successor/predecessor se replace, then that node remove.
  • Inorder traversal: sorted order deta hai for a BST with unique keys.
OperationTypical balancedWorst skewed

5.7 General (m-ary) trees

General tree mein node ke children ki count fixed two tak limited nahi hoti. M-ary tree mein each node ke maximum m children ho sakte hain. Binary representation ke common idea: left-child/right-sibling — first child ko left pointer, next sibling ko right pointer se represent karte hain.

Exam-ready answers: 2, 4 & 6 marks

Answers concise rakhe hain; diagram ya algorithm question mein labelled diagram/steps add karo.

2 marks — Define a binary tree.

A binary tree is a tree that is either empty or consists of a root node and left and right binary subtrees. Each node has at most two children.

2 marks — What is a leaf node?

A node with no children is called a leaf node (also called an external node).

2 marks — State traversal orders.

Preorder: Root-Left-Right; Inorder: Left-Root-Right; Postorder: Left-Right-Root.

4 marks — Differentiate array and linked representation.

Array representation stores nodes at indices and is convenient for complete trees. With 0-based indexing, children of i are 2i+1 and 2i+2. It may waste space for sparse trees and resizing is inconvenient. Linked representation stores data with left/right pointers; NULL denotes absent subtrees. It supports flexible shapes and pointer-based insertion/deletion, but uses pointer memory and parent lookup is not direct.

4 marks — Explain three traversals.

Preorder visits root, left subtree, right subtree. Inorder visits left, root, right. Postorder visits left, right, root. For tree A with children B,C and B with D,E, the outputs are respectively A B D E C; D B E A C; D E B C A.

6 marks — Explain BST and its operations.

A Binary Search Tree is a binary tree in which keys in the left subtree are smaller than the node and keys in the right subtree are larger (for unique keys). Search compares the target with the current node and moves left or right. Insertion follows the same comparisons until a NULL position is found. Deletion has three cases: leaf node removal; one-child node replaced by its child; two-child node replaced by its inorder successor or predecessor. Inorder traversal of a BST gives sorted keys. Average balanced operations are O(log n), while a skewed tree may require O(n).

6 marks — Explain tree traversals with example.

Traversal means visiting all nodes systematically. Consider A as root, B and C its children, and D/E children of B. Preorder (NLR) = A B D E C; Inorder (LNR) = D B E A C; Postorder (LRN) = D E B C A. Recursive algorithms check NULL, then call left/right subtree traversals in the required order. Draw the tree and write each sequence for full marks.

C program: recursive traversals

Supplementary, standard C example for a small fixed tree. The traversal logic matches the chapter topic.

#include <stdio.h>
struct Node {
    char data;
    struct Node *left, *right;
};
void preorder(struct Node *r) {
    if (r != NULL) {
        printf("%c ", r->data);
        preorder(r->left);
        preorder(r->right);
    }
}
void inorder(struct Node *r) {
    if (r != NULL) {
        inorder(r->left);
        printf("%c ", r->data);
        inorder(r->right);
    }
}
void postorder(struct Node *r) {
    if (r != NULL) {
        postorder(r->left);
        postorder(r->right);
        printf("%c ", r->data);
    }
}

Note: This excerpt demonstrates traversal functions; it omits allocation and main() to keep the algorithm readable.

C program: BST search (core function)

struct Node {
    int key;
    struct Node *left, *right;
};
struct Node *search(struct Node *root, int key) {
    if (root == NULL || root->key == key)
        return root;
    if (key < root->key)
        return search(root->left, key);
    return search(root->right, key);
}

Last-minute recap

  • Binary node: maximum two children.
  • Preorder = NLR; Inorder = LNR; Postorder = LRN.
  • In a BST, inorder traversal returns sorted keys (unique-key convention).
  • Array children for 0-based index i: 2i+1 and 2i+2.
  • DFS explores depth; BFS explores level by level.
  • Expression tree: operators internal, operands leaves.
