Quick revision notes

Short, scan-friendly notes from the PDF.

1. Classes and Objects

  • Class: blueprint/template defining fields and methods.
  • Object: instance of a class representing a specific entity.
  • PDF example: Dog is a class; Tommy is an object.
  • Instance-member memory is allocated when an object is created; static members are associated with class loading (as stated in the notes).

2. Access modifiers

ModifierAccess described in PDF
privateOnly within the same class
defaultWithin the same package
protectedSame package and subclasses in different packages
publicAccessible from anywhere

Memory order from least to most access: private → default → protected → public.

3. Constructors

  • Special member called when an object is created; initializes object state.
  • Same name as class; no return type, not even void.
  • May accept parameters to initialize fields.
  • PDF discusses default, parameterized and copy constructors.

4. Constructor overloading

  • One class has multiple constructors with different parameter lists.
  • The constructor is selected at compile time based on arguments.
  • Useful for initializing objects with different data, default values and simpler object creation.
Clarification added: In Java, the compiler supplies a no-argument default constructor only when no constructor is declared in the class. A user-written no-argument constructor is commonly called a no-argument constructor; it is not the compiler-provided default constructor in the strict sense.
