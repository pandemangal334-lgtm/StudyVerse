Topic 01

Polymorphism in Java

High-yield concept
Simple meaning

One name, many forms

Polymorphism is the ability of an object or method to take different forms. The same method name can perform different tasks based on parameters or the actual object.

Memory hook: Poly = many, morphs = forms.
Two types · source PDF

Compile-time vs runtime

  • Compile-time: method overloading; compiler selects a method using parameter number, types and order.
  • Runtime: method overriding; the actual object determines the implementation at runtime.

Compile-time example

class Calculation { int add(int a, int b) { return a + b; } double add(double a, double b) { return a + b; } } // add(5, 3) → 8 // add(2.5, 3.7) → 6.2

The parameter types determine which overloaded method is selected.

Runtime example · Bike/Splendor

class Bike { void run() { System.out.println("running"); } } class Splendor extends Bike { void run() { System.out.println("running safely with 60km"); } } Bike b = new Splendor(); // upcasting b.run();

Output: running safely with 60km. The overridden subclass method runs.

Upcasting

When a parent-class reference variable refers to a child-class object, it is called upcasting.

Bike b = new Splendor();

The reference type controls which members are accessible; for an overridden instance method, the actual object determines the implementation.

Advantages listed in the PDF

Code reusability

Reuse and consistent interfaces.

Flexibility

Extend behaviour without changing existing code.

Dynamic invocation

Method selected by actual object at runtime.

Interface implementation

Different classes treated through a common interface.

Method overloading

Same name, different parameter lists.

Lower complexity

Modular, maintainable class structure.

Topic 03

Abstraction in Java

Definition

Abstraction is the process of hiding internal implementation details and showing only essential functionality. It focuses on what an object does rather than how it does it.

Real-life example from the PDF: a TV remote. You press buttons without needing to understand the TV's internal technology.

Ways to achieve abstraction

  • Abstract class: the PDF describes it as providing 0% to 100% abstraction.
  • Interface: the PDF describes it as providing 100% abstraction.

Clarification / addition: modern Java interfaces can also contain default, static and private methods, so “100% abstraction” is a common introductory simplification rather than a complete description of every interface feature.

Topic 04

Abstract class

An abstract class is declared with the abstract keyword and cannot be instantiated directly. It can provide a common base for related classes, with abstract methods and implemented methods.

abstract class Shape { abstract void draw(); // no body void info() { // concrete method System.out.println("A shape"); } } class Circle extends Shape { void draw() { System.out.println("Drawing circle"); } } class Main { public static void main(String[] args) { Shape s = new Circle(); s.draw(); s.info(); } }

Rules to remember from the PDF

  • Must be declared using abstract.
  • Can contain abstract and non-abstract methods.
  • Cannot be instantiated directly.
  • Can have constructors and static methods.
  • Can have final methods; subclasses cannot override those final methods.
  • An abstract class may have no abstract methods and still cannot be instantiated.
  • If a class contains an abstract method, the class must itself be abstract.
Exam trap: You can create a reference of an abstract class type, such as Shape s = new Circle();, but not an object with new Shape().
Topic 05

Abstract method

Definition & syntax

An abstract method is declared without a body using the abstract keyword. It specifies what a method should do and leaves implementation to a subclass.

abstract returnType methodName(parameterList);

Example: abstract void printInfo();

PDF example pattern

abstract class ArithmeticOperation { abstract void printInfo(); } class Add extends ArithmeticOperation { void printInfo() { int a = 3, b = 4; System.out.println(a + b); } } class Sub extends ArithmeticOperation { void printInfo() { int a = 4, b = 5; System.out.println(a - b); } }

The PDF explains that Add and Sub implement the method differently; a superclass reference can call the appropriate implementation at runtime.

Topic 06

Interface

Core idea

The PDF describes interface methods as abstract by default unless declared default, static or private.

Easy memory hook from PDF:
Interface → WHAT
Implementation class → HOW
  • An abstract interface method has no body.
  • A class implementing the interface must implement its abstract methods.
  • The implemented method must be declared public.
  • An interface can contain multiple abstract methods.
  • A class can implement multiple interfaces.

Example: Animal and Dog

interface Animal { void sound(); } class Dog implements Animal { public void sound() { System.out.println("Dog barks"); } } class Main { public static void main(String[] args) { Dog dog = new Dog(); dog.sound(); } }

Why use an interface?

  • Achieve abstraction.
  • Support multiple inheritance of type through multiple interfaces.
  • Reduce coupling and improve flexibility and maintainability.
