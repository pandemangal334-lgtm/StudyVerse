3.1 · Linked list concepts

Linked list kya hai?

Linked list ek non-sequential, dynamic data structure hai. Har item ek node mein hota hai; node ke data ke saath pointer/link hota hai jo next node ka address rakhta hai. Nodes memory mein continuous hona zaroori nahi.

Hinglish: array mein elements index se milte hain; linked list mein start pointer se shuru karke next pointers follow karte hain.

PDF ke mutabik nodes commonly malloc() se heap par allocate hote hain aur unused memory ko free() se release kiya ja sakta hai.

Advantages & limitations

Pros / cons

Advantages (PDF): dynamic size, memory allocated when required, insertion/deletion can be efficient, useful in complex applications.

Disadvantages (PDF): extra memory for pointers and searching a particular element can be time-consuming.

3.2 · Types

Four linked-list types

  • Singly: data + next; forward traversal.
  • Doubly: previous/left + data + next/right; forward and backward traversal.
  • Circular singly: last node points back to first; no NULL link in a non-empty list.
  • Circular doubly: next of last points to first, previous of first points to last.

Operations

Insertion / deletion logic

Insert at beginning (singly): new->next = start; start = new.

Delete beginning: temp = start; start = start->next; free(temp).

Traverse: temp=start; while(temp != NULL) { print data; temp=temp->next; }.

Pointer update order important hai. Delete karne se pehle next address save/update karo; freed node ko dobara access mat karo.

Header & array-based lists

Header node: an extra node at the beginning can simplify special-case insertion/deletion. PDF notes that it should not be counted as a real data node.

2 marks

Define linked list.

A linked list is a non-sequential, dynamic collection of nodes. Each node stores data and one or more links that identify another node in the list.

2 marks

What is a self-referential structure?

A structure that contains a pointer to another object of its own structure type. Example: struct node { int data; struct node *next; };

4 marks

Write advantages and disadvantages of linked lists.

Advantages: dynamic size; memory allocated/deallocated as needed; insertion and deletion can be efficient; supports complex data-structure implementations. Disadvantages: extra pointer memory; searching is often time-consuming because nodes must be traversed.

4 marks

Differentiate singly and doubly linked lists.

1. Singly node stores data and next pointer; doubly node stores previous, data and next. 2. Singly traversal is forward; doubly supports forward and backward traversal. 3. Singly uses one link per node; doubly uses two. 4. Doubly can simplify operations needing predecessor access, but uses more pointer memory.

4 marks

Compare array and linked list.

Arrays have fixed declared size and efficient indexed/random access. Linked lists can grow/shrink and insertion/deletion can avoid shifting elements, but access requires traversal. Linked-list nodes also need extra pointer storage; array elements are stored in an array block while linked nodes may be separately allocated.

6 marks

Explain singly linked list with node structure and operations.

A singly linked list is a linear sequence of nodes. Each node has a data field and a next pointer. A start pointer points to the first node; the last node's next is NULL. Nodes can be allocated with malloc and released with free. Basic operations are creation, insertion, deletion and traversal.

struct node { int data; struct node *next; };
struct node *start = NULL;

Insertion at beginning: set newnode->next=start, then start=newnode. Deletion at beginning: if start is not NULL, store start in temp, advance start=start->next, then free(temp). Traversal begins at start and follows next until NULL.

6 marks

Explain types of linked lists.

1. Singly: each node points to next; last points to NULL. 2. Doubly: previous and next links enable bidirectional traversal. 3. Circular singly: last node links to first, forming a loop. 4. Circular doubly: both next and previous links wrap around, so the last and first nodes link in both directions.

1. Singly linked list: create, display, insert at beginning, delete at beginning

#include <stdio.h>
#include <stdlib.h>

struct node { int data; struct node *next; };
struct node *start = NULL;

void insert_begin(int value) {
    struct node *n = malloc(sizeof *n);
    if (!n) { puts("Allocation failed"); return; }
    n->data = value;
    n->next = start;
    start = n;
}
void display(void) {
    struct node *p = start;
    while (p != NULL) {
        printf("%d -> ", p->data);
        p = p->next;
    }
    puts("NULL");
}
void delete_begin(void) {
    if (start == NULL) { puts("List is empty"); return; }
    struct node *temp = start;
    start = start->next;
    free(temp);
}
void free_list(void) {
    while (start != NULL) delete_begin();
}
int main(void) {
    insert_begin(30); insert_begin(20); insert_begin(10);
    display();
    delete_begin();
    display();
    free_list();
    return 0;
}

Output:

10 -> 20 -> 30 -> NULL
20 -> 30 -> NULL

3. Circular singly linked list: traversal

/* start points to first node; last->next points to start */
void display_circular(struct node *start) {
    if (start == NULL) { puts("Empty"); return; }
    struct node *p = start;
    do {
        printf("%d ", p->data);
        p = p->next;
    } while (p != start);
    puts("");
}

Supplementary traversal example. Unlike a normal singly list, stop when traversal returns to start, not when it reaches NULL.
