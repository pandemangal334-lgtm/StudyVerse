Joint Probability • Marginal Functions • Joint Distribution • Continuous Density

1. Joint probability

Jab do random variables X aur Y ki values ek saath di hoti hain, joint probability batati hai ki X bhi particular value ho aur Y bhi particular value ho.

f(x,y) = P(X = x, Y = y)

Discrete joint table ki saari probabilities ka total 1 hota hai.

2. Marginal probability functions

Marginal matlab sirf ek variable ki probability. Doosre variable ki saari values ko add ya integrate karke hata dete hain.

Discrete: fX(x) = Σy f(x,y)   |   fY(y) = Σx f(x,y)
Continuous: fX(x) = ∫ f(x,y) dy   |   fY(y) = ∫ f(x,y) dx

Yaad rakh: fX chahiye to y ko sum/integrate out karo. fY chahiye to x ko sum/integrate out karo.

3. PDF wala discrete numerical

Table entries: c, 2c, 3c / 2c, 4c, 6c / 3c, 6c, 9c.

All entries ka total = 36c. Total probability 1 hoti hai.

36c = 1 ⇒ c = 1/36

Row totals se fX(x)=x/6 aur column totals se fY(y)=y/6, x,y=1,2,3.

Independence check: fX(x)fY(y)=(x/6)(y/6)=xy/36=f(x,y). Isliye X aur Y independent hain.

4. Continuous joint density

Valid density non-negative hoti hai aur full region par double integral 1 hota hai.

∫∫ f(x,y) dx dy = 1
F(x,y) = ∫ from −∞ to x ∫ from −∞ to y f(u,v) dv du

Marginal X ke liye y par integrate karo; marginal Y ke liye x par integrate karo.

5. Continuous numerical: c(2x+y)

Given f(x,y)=c(2x+y), 0<x<1, 0<y<2.

c ∫₀¹ ∫₀² (2x+y) dy dx = 1

Inner integral = 4x+2. Outer integral ∫₀¹(4x+2)dx=4. So 4c=1 and c=1/4.

fX(x)=(2x+1)/2, 0<x<1
fY(y)=(1+y)/4, 0<y<2

Notes ke doosre region 2<x<6, 0<y<5 ke results: c=1/210, fX(x)=(4x+5)/84, fY(y)=(16+2y)/105.

Last-minute revision

  • Joint PMF: f(x,y)=P(X=x,Y=y).
  • Discrete probabilities ka total = 1.
  • Marginal X: y par sum/integrate; marginal Y: x par sum/integrate.
  • Continuous density non-negative; total double integral = 1.
  • Joint CDF: F(x,y)=P(X≤x,Y≤y).
  • Independence: f(x,y)=fX(x)fY(y).
  • Discrete region probability: required cells add karo.
  • Continuous region probability: density ko required region par integrate karo.

Important 2-mark answers

1. Define joint probability function.

For two discrete random variables X and Y, f(x,y)=P(X=x,Y=y). It gives the probability that both events occur together.

2. What are marginal functions?

Marginal functions give the distribution of one variable separately. Discrete: fX(x)=Σy f(x,y), fY(y)=Σx f(x,y).

3. Condition for continuous density?

f(x,y) must be non-negative and its double integral over the whole valid region must equal 1.

4. Write continuous marginal formulas.

fX(x)=∫f(x,y)dy over allowed y; fY(y)=∫f(x,y)dx over allowed x.

5. Condition for independence?

X and Y independent if f(x,y)=fX(x)fY(y) for all valid x,y.

Important 4-mark answers

1. How to find marginals from a discrete joint table?

To find fX(x), add each row across all y values. To find fY(y), add each column across all x values. In the notes, total=36c, so c=1/36; fX=x/6 and fY=y/6 for x,y=1,2,3.

2. Find c for f=c(2x+y), 0<x<1, 0<y<2.

∫₀¹∫₀²c(2x+y)dy dx=1. Inner integral is 4x+2. Then ∫₀¹(4x+2)dx=4. Thus 4c=1 and c=1/4.

3. Find marginal densities for that example.

fX(x)=∫₀²(1/4)(2x+y)dy=(2x+1)/2. fY(y)=∫₀¹(1/4)(2x+y)dx=(1+y)/4.

4. Explain joint distribution function.

F(x,y)=P(X≤x,Y≤y). For continuous variables, integrate the joint density over the region u≤x and v≤y.
